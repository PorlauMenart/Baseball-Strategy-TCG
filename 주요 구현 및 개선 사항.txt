1. 카드 Drag & Drop 시스템 구현 및 End Turn UI 위치 개선
- 마우스 드래그앤드롭을 통한 카드 사용 기능 구현
- 게임 진행 흐름에 맞게 End Turn 버튼 위치 및 UI 조정

2. 동전 던지기 연출 및 화면 처리
- 선공·후공 결정을 위한 동전 던지기 기능 구현
- 동전 던지기 진행 중 다른 카드와 UI를 숨겨 연출에 집중할 수 있도록 개선

3. Coroutine을 활용한 상대방 행동 지연
- AI가 즉시 행동하지 않고 일정 시간 후 행동하도록 구현
- 실제 상대와 플레이하는 것처럼 자연스러운 게임 진행 연출

4. 득점 카드 처리 기능 구현
- 공격 카드 사용으로 득점이 발생했을 때 해당 공격 카드가 정상적으로 처리·표시되도록 게임 로직 구현

5. 게임 로그 시스템 개선
- 카드 사용, 공격·수비 결과, 득점 등 주요 게임 진행 상황을 확인할 수 있도록 로그 출력 기능 수정

6. 게임 UI 제작 및 개선
- 카드별 UI 구성
- 스코어보드 구현
- 타이틀 Scene 제작
- 동전 던지기 UI 및 게임 진행 화면 개선

7. 게임 AI 알고리즘 구현 및 머신러닝 실험
- MCTS 기반 AI 의사결정 시스템 구현
- 상대 패 샘플링 및 UCB1을 활용한 탐색 로직 적용
- 머신러닝 모델 적용을 위한 데이터 및 테스트 환경 구성

8. 덱 시스템 구현
- 카드 덱 구성 및 관리 기능 개발
- 플레이어 및 AI가 서로 다른 덱을 사용할 수 있도록 게임 구조 구현

9. 특수 능력을 가진 영웅 카드 구현
- 일정 확률로 안타를 방어하는 등 카드별 특수 능력 구현
- 확률 기반 효과를 게임 결과에 반영

10. 싱글플레이 AI 덱 콘셉트 다양화
- 상대 AI마다 서로 다른 플레이 스타일을 갖도록 덱 구성
- 수비 중심 + 홈런 전략
- 공격 중심 전략
- 다수의 투수 카드를 활용하는 ‘벌떼 투수’ 전략 등 구현

11. 튜토리얼 시스템 구현
- 처음 플레이하는 사용자가 카드 사용법과 게임 진행 방식을 익힐 수 있도록 튜토리얼 Scene 및 진행 로직 구현
